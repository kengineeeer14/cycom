
# Logger 詳細設計

## 1. 基本情報

| 項目 | 内容 |
|---|---|
| クラスID | CL-005 |
| クラス名 | Logger |
| 担当機能ID | F-004、F-005 |

## 2. 関数一覧

| 関数ID | 関数名 | 対応機能ID | 処理内容 |
|---|---|---|---|
| FN-011 | Start | F-005 | log onの場合、CSVファイルを開く |
| FN-012 | LoggingLoop | F-005 | 指定された周期でCSVにログを記録する |
| FN-013 | Stop | F-005 | CSVファイルを閉じる |

## 3. 詳細仕様

### FN-011 Start

- log onの場合、CSVファイルを開く。
- CSVファイルの1行目にヘッダを書き込む。

### FN-012 LoggingLoop

- log onの場合、指定された周期でCSVにログを記録する。
- log offの場合、ログを記録しない。

### FN-013 Stop

- 終了時にCSVファイルを閉じる。
