
# Logger 詳細設計

## 1. クラスの責務

記録対象の走行情報を取得し、設定に従ってCSVファイルへ記録する。

## 2. 関数一覧

| 関数名 | 対応機能ID | 処理内容 |
|---|---|---|
| Start | F-005 | log onの場合、CSVファイルを開く |
| LoggingLoop | F-005 | 指定された周期でCSVにログを記録する |
| Stop | F-005 | CSVファイルを閉じる |

## 3. 詳細仕様

### Start

- log onの場合、CSVファイルを開く。
- CSVファイルの1行目にヘッダを書き込む。

### LoggingLoop

- log onの場合、指定された周期でCSVにログを記録する。
- log offの場合、ログを記録しない。

### Stop

- 終了時にCSVファイルを閉じる。
