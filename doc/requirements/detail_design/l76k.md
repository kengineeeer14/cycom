
# L76k 詳細設計

## 1. クラスの責務

GPSモジュールL76kが出力するNMEA文を解析し、表示やログ記録に必要な走行情報を提供する。

## 2. 関数一覧

| 関数名 | 対応機能ID | 処理内容 |
|---|---|---|
| ParseGnrmc | F-002 | GNRMCのデータを解析する |
| ParseGngga | F-002 | GNGGAのデータを解析する |
| ParseGnvtg | F-002 | GNVTGのデータを解析する |
| GetGnvtgSpeed | F-002 | 取得したデータから画面表示用の速度を抽出する |
| Snapshot | F-004 | 取得したデータからログ用のデータを抽出する |

## 3. 詳細仕様

### ParseGnrmc

- GNRMCのデータを解析する。

### ParseGngga

- GNGGAのデータを解析する。

### ParseGnvtg

- GNVTGのデータを解析する。

### GetGnvtgSpeed

- 取得したデータから画面表示用の速度を抽出する。

### Snapshot

- 取得したデータからログ用のデータを抽出する。
- ログ用データの取得中に、対象データが更新されないようにする。
