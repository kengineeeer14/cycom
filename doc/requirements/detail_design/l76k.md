
# L76k 詳細設計

## 1. 基本情報

| 項目 | 内容 |
|---|---|
| クラスID | CL-002 |
| クラス名 | L76k |
| 担当機能ID | F-002、F-004 |

## 2. 関数一覧

| 関数ID | 関数名 | 対応機能ID | 処理内容 |
|---|---|---|---|
| FN-003 | ParseGnrmc | F-002 | GNRMCのデータを解析する |
| FN-004 | ParseGngga | F-002 | GNGGAのデータを解析する |
| FN-005 | ParseGnvtg | F-002 | GNVTGのデータを解析する |
| FN-006 | GetGnvtgSpeed | F-002 | 取得したデータから画面表示用の速度を抽出する |
| FN-007 | Snapshot | F-004 | 取得したデータからログ用のデータを抽出する |

## 3. 詳細仕様

### FN-003 ParseGnrmc

- GNRMCのデータを解析する。

### FN-004 ParseGngga

- GNGGAのデータを解析する。

### FN-005 ParseGnvtg

- GNVTGのデータを解析する。

### FN-006 GetGnvtgSpeed

- 取得したデータから画面表示用の速度を抽出する。

### FN-007 Snapshot

- 取得したデータからログ用のデータを抽出する。
- ログ用データの取得中に、対象データが更新されないようにする。
