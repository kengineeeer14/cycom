
# SensorManager 詳細設計

## 1. クラスの責務

GPSモジュールからデータを受信し、NMEA文を取り出して後続の解析処理に渡す。

## 2. 関数・処理一覧

| 関数名・処理名 | 対応機能ID | 処理内容 |
|---|---|---|
| データ受信処理 | F-001 | GPSの受信データをバッファに蓄積する |
| NMEA分割処理 | F-001 | 改行を区切りとしてNMEA文を取り出す |

## 3. 詳細仕様

### データ受信処理

- GPSの受信データをバッファに蓄積する。

### NMEA分割処理

- バッファから改行で区切られたNMEA文を取り出す。
