
# SensorManager 詳細設計

## 1. 基本情報

| 項目 | 内容 |
|---|---|
| クラスID | CL-001 |
| クラス名 | SensorManager |
| 担当機能ID | F-001、F-002 |

## 2. 関数・処理一覧

| 関数ID | 関数名・処理名 | 対応機能ID | 処理内容 |
|---|---|---|---|
| FN-001 | データ受信処理 | F-001 | GPSの受信データをバッファに蓄積する |
| FN-002 | NMEA分割処理 | F-001 | 改行を区切りとしてNMEA文を取り出す |

## 3. 詳細仕様

### FN-001 データ受信処理

- GPSの受信データをバッファに蓄積する。

### FN-002 NMEA分割処理

- バッファから改行で区切られたNMEA文を取り出す。
