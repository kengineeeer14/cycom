
# 要件定義

## 1. 要件一覧

| 要件ID | 上位要件ID | 要件内容 | 備考 |
|---|---|---|---|
| CR-000 | - | 自転車の走行状態を把握できること | |
| CR-001 | CR-000 | 走行状態に関する情報を継続的に取得・表示・記録できること | |
| SYS-001 | CR-001 | 走行状態に関する情報を継続的に取得できること | |
| SYS-002 | CR-001 | 取得した走行状態に関する情報を継続的に表示できること | |
| SYS-003 | CR-001 | 取得した走行状態に関する情報を継続的に記録できること | |
| CR-002 | CR-000 | サイコンの画面を意図通りに操作できること | |
| SYS-004 | CR-002 | サイコンはタッチで操作できること | |

## 2. 要件IDの定義

| 接頭辞 | 意味 | 説明 |
|---|---|---|
| CR | Customer Requirement | ユーザー視点の要求 |
| SYS | System Requirement | システムが満たすべき要件 |
